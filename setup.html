🎮 행복 인벤토리 — 선생님용 설정 페이지

코드를 건드리지 않고도, 학생 제출 데이터가 본인의 구글 시트로 들어오는 링크를 만들 수 있습니다.

1새 구글 스프레드시트 만들기

구글 드라이브에서 빈 스프레드시트를 하나 새로 만드세요. (이름은 자유롭게)

2Apps Script 코드 붙여넣기

방금 만든 스프레드시트에서 확장 프로그램 → Apps Script 클릭 → 기존 코드를 모두 지우고, 아래 코드를 그대로 통째로 붙여넣은 뒤 저장(Ctrl+S)하세요.

3웹 앱으로 배포하기

Apps Script 에디터 우측 상단 배포 → 새 배포 클릭 → ⚙️ 아이콘에서 웹 앱 선택
· 실행 사용자: 나
· 액세스 권한: 모든 사용자
배포 후 나오는 웹 앱 URL을 복사하세요. (구글 권한 승인 팝업이 뜨면 "고급" → 허용)

4학생용 링크 만들기

위에서 복사한 배포 URL을 아래에 붙여넣고 버튼을 누르세요.
